# Skill Gap Analyzer 🚀

## About the Project
Skill Gap Analyzer is a web-based application that helps students identify missing skills for their desired job roles by comparing their existing skills with required job skills.

## Features
- Enter your existing skills.
- Select your desired job role.
- View matched and missing skills.
- Calculate skill match percentage.
- Get suggestions for skill improvement.

## Technologies Used
- Python
- Flask
- HTML
- CSS

## How to Run the Project

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open `http://127.0.0.1:5000` in your browser.
